# ShapeForge³ V4

GitHub-ready static application foundation for ShapeForge³.

## Included
- Responsive app shell and navigation
- Home workshop
- Forge 60-second journey
- Photo/video scan intake
- Projects
- Model library
- Print estimate demo
- Dashboard and settings
- PWA manifest
- Netlify configuration

## Important
This release contains working front-end interactions and local browser storage.
Real AI model generation, photogrammetry, authentication, cloud storage, payments,
marketplace transactions and production print quotes require backend services and API keys.

## Deploy
Upload all files and folders to the repository root on the `main` branch.
Netlify will publish automatically with the existing GitHub connection.
