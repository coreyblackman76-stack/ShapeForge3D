# ShapeForge³ V3 Complete Source

This is the complete GitHub-ready static source for the current ShapeForge³ workspace.

## Upload to GitHub
Upload every file and folder in this package to the root of the `ShapeForge3D` repository, then commit to `main`.

## Netlify
The existing GitHub connection can keep these settings blank:
- Base directory: blank
- Build command: blank
- Publish directory: blank

Netlify will publish `index.html` and the `assets` folder directly.
